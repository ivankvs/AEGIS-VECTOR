# AEGIS VECTOR v1.5 — Geo Map & Budget HUD

## Що це за версія

v1.5 продовжує v1.4 Stage 1. Це браузерна демоверсія тактичної гри ППО, а не достовірний військовий симулятор чи система бойового управління.

## Що змінилося

### 1. Бюджет
- Баланс командування тепер має явний підпис **БЮДЖЕТ**.
- Бюджет відображається і на вузьких мобільних екранах; раніше весь блок телеметрії ховався CSS-правилом для mobile.
- Значення форматується з розділювачами тисяч.
- У грі використовується умовна ігрова валюта `$`, а не гривня та не реальні кошти.

### 2. Географія
- Під час запуску завантажуються адміністративні полігони України з OSM-derived GeoJSON: `Ukraine.geojson`.
- На карті показуються межі регіонів та 17 додаткових географічних міст-підписів.
- Координати восьми стратегічних міст прив'язані до географічних координат центрів міст.
- Межа дозволеного розміщення підрозділів використовує завантажені геополігони, коли вони доступні.
- Виправлено локальну проєкцію карти: ширина/висота більше не мають попереднього помітного спотворення; масштаб і дальності перераховані узгоджено.
- У мінікарті показується атрибуція OpenStreetMap та джерела GeoJSON.

**Важливо:** це географічна основа з адміністративними межами та містами, а не повна топографічна карта. Тут ще немає рельєфу, дорожньої мережі, повної гідрографії, висот, радіогоризонту чи геодезичної сітки MGRS.

### 3. Офлайн-режим карти
- Геодані завантажуються з CDN під час відкриття HTML.
- Якщо мережі немає або запит не проходить, гра використовує попередню схематичну геометрію та явно показує `СХЕМА • OFFLINE / НЕМАЄ МЕРЕЖІ`.
- Отже, точні регіональні межі доступні лише за умови успішного завантаження GeoJSON.

### 4. Додаткові виправлення
- Виправлено Shift-мульти-розміщення підрозділів на desktop.
- Оптимізовано оновлення списку міст і доку підрозділів: DOM більше не перебудовується повністю чотири рази на секунду без зміни даних.
- Перезапуск операції тепер скидає чергу хвилі, статистику, таймери та попередження.
- Під час відновлення збереження камера не повинна скидатися у FIT при наступному resize.
- Виправлено обробку нульового `hitChance` та перемішування коридорів через Fisher–Yates.

## Як відкрити

1. Завантажте ZIP та розпакуйте його.
2. Відкрийте `AEGIS_VECTOR_v1_5.html` у Chrome або Edge.
3. Для завантаження регіональних геоданих потрібен доступ до інтернету.
4. Якщо статус показує `СХЕМА • OFFLINE / НЕМАЄ МЕРЕЖІ`, це означає, що GeoJSON не завантажився; гра продовжить роботу на схематичній карті.

## Керування

- Миша / один палець: вибір об'єкта або позиції.
- Перетягування: панорамування карти.
- Коліщатко / pinch: масштаб.
- `F`: FIT усієї карти.
- `Space`: пауза / продовження.
- `1–5`: вибір типу підрозділу.
- `Esc`: скасування розміщення / закриття інспектора.
- `Shift` + клік: послідовне розміщення однакових підрозділів на desktop.

## Джерела геоданих та ліцензія

- GeoJSON: `https://github.com/darmat1/ukraine-geo-data`
- CDN-файл: `https://cdn.jsdelivr.net/gh/darmat1/ukraine-geo-data@main/geodata/Ukraine.geojson`
- Репозиторій описує адміністративні межі з OpenStreetMap та ліцензію ODbL. На карті залишено видиму атрибуцію `© OpenStreetMap contributors`.
- Для production потрібно зафіксувати конкретну версію/commit геоданих, перевірити актуальну ліцензійну сумісність та бажано зберігати перевірений локальний набір даних.

## Межі демоверсії

- Збереження локальне (localStorage), без серверного профілю.
- Немає мережевого мультиплеєра, рейтингу, античіту чи синхронізації секторів.
- Немає висотних шарів, рельєфу, радіогоризонту, повноцінного sensor fusion, каналів обстрілу та детальної моделі перехоплення.
- Параметри озброєння та економіки залишаються ігровими абстракціями.
- Tailwind CDN і Google Fonts залишаються зовнішніми залежностями.
